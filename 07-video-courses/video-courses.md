# Free Video Courses - Data Engineer / Data Analyst Path

Free full-length video courses and playlists, in learning order. All links were checked on 2026-11-21 (YouTube via oEmbed: the ID resolves to the stated title and channel; course pages via HTTP or web search).

Language: EN = English, ES = Spanish. Length is runtime for single videos, or the video count for playlists.

Suggested path for a C#/C++/TS + AWS + Postgres dev: Python/pandas -> advanced SQL -> stats -> BI tools (analyst roles) -> data modeling -> DE bootcamp (Zoomcamp or Zach Wilson) -> Docker/Terraform -> dbt -> Airflow -> Spark -> Kafka -> AWS DEA-C01 -> CMU internals (keep going in parallel).

## Not included (could not verify as free video courses)

- **Platzi**: courses are on platzi.com and most lessons need a subscription. Free access is only for limited-time events, so none are listed.
- **Official Kimball Group / Margy Ross lecture videos**: no free official recordings found. Use the Coalesce talk above plus *The Data Warehouse Toolkit* (book).
- **Stanford / Berkeley database lectures**: only unofficial re-uploads found on YouTube. MIT and CMU official playlists are used instead.
