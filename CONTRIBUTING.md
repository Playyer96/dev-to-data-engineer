# Contributing

Thanks for helping keep this guide useful! The goal is a **free, ordered, verified** path from software developer to Data Engineer / Analyst.

## Rules for resources
1. **Free only.** Free audit, free tier, or free trial is OK if clearly labeled. No paid-only links except books marked *(paid)*.
2. **Legal only.** Never link pirated books or courses.
3. **Verified.** Open the link before submitting. No dead links or link shorteners.
4. **Ordered.** Put the resource where it fits in the learning sequence, not at the bottom.
5. **One line on why.** Each entry says what it covers and why it's worth the time.

## How to contribute
- Small fixes (broken link, typo): open a PR directly.
- New resource or section: open an issue first using the templates.
- Spreadsheets (`.xlsx`) mirror the Markdown files. If you change a list, update the `.md` and note it in the PR. Maintainers regenerate the `.xlsx`.

## PDFs
PDFs are **not** committed. Add the source URL to `scripts/download-pdfs.sh` instead.
